We are building an open-source, map-first hyper-local community web and mobile-responsive app called "PulseMap" (for people, not companies) following a strict AI-Native SDLC workflow.

STEP A — GENERATE AI-NATIVE SDLC DOCUMENTATION FILES FIRST:
Create a `/docs` folder in the project root plus an MIT `LICENSE` and `README.md`:
1. `docs/1_PRD.md`: Document our problem statement, target users (students & neighborhood/compound residents), user stories, age-limit guardrails, and privacy rules.
2. `docs/2_ARCHITECTURE.md`: Document our tech stack (React, Tailwind, Leaflet + CartoDB Voyager free tiles, `emoji-picker-react`, Node/Express, SQLite/PostgreSQL database) and the 4-table schema (`users`, `events`, `event_attendees`, `messages`).
3. `docs/3_DESIGN_SPEC.md`: Document our UI design system, custom floating Emoji Map Markers, DiceBear avatar integration, and responsive desktop/mobile drawer layout.

STEP B — BUILD THE FULL-STACK APPLICATION:

1. BEAUTIFUL UI, MAP THEME & EMOJI PACKAGE:
- Use `react-leaflet` with free **CartoDB Voyager** map tiles (`https://{s}.basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}{r}.png`) for a sleek, modern consumer map look (no API key needed). Center default map on Istanbul (around Kadıköy / Beşiktaş / Campus areas).
- Install and use `emoji-picker-react` (or high-res Apple/Twemoji/Fluent emoji rendering) so emojis look crisp and vibrant across all devices, plus quick-select preset activity emojis (`☕`, `🏐`, `🏃`, `🗣️`, `⚽`, `🎮`, `📚`, `🎸`, `🍕`, `🧘`).
- Use free DiceBear illustrated avatars (`https://api.dicebear.com/9.x/avataaars/svg?seed=...`) so every user and attendee has a beautiful circular profile picture.
- Add a "📱 Mobile View / 🖥️ Desktop View" toggle in the top bar so hackathon judges can test both mobile and desktop layouts smoothly.

2. LIGHTWEIGHT USERNAME + PASSWORD AUTH (NO EMAIL OR PHONE):
- Users register/login with ONLY: unique `username` (if already taken in DB, show a clear error: "Username is already taken, please choose another"), `password`, `age` (number, e.g., 22), and an interactive Avatar Picker (choose from 8 DiceBear avatar presets).
- Store users in the database and include a quick "Switch Demo User" helper in the corner so judges can easily test hosting vs. joining vs. messaging from different accounts and ages.

3. MAIN MAP PAGE + INSTANT SEARCH & FILTERS:
- Top Floating Search & Filter Bar:
  - Search input: Instant search for phrases like "coffee talks", "running", "volleyball match", or "coffee talk in english to practice" that filters both map pins and the sidebar list live.
  - Filter pills: All, ☕ Coffee & Talks, 🏐 Sports, 🏃 Running, 📚 Study, 🎮 Games, plus toggles for "Fits My Age" and "Open Spots Only".
- Custom Floating Emoji Map Pins:
  - Render each event on the map at its pinned `lat, lng` using a custom HTML `L.divIcon` pill: a glossy white rounded badge with a drop shadow, showing the large Event Emoji (e.g., `🏐`) and a live capacity pill (`4/6` in emerald green when open, or `6/6 Full` in slate gray).
  - Clicking any map pin opens a rich Event Card modal/drawer.

4. CREATE EVENT MODAL (WITH MAP PIN PICKER & EMOJI PICKER):
- Clicking "+ Create Event" lets the user click on the map (or drag a pin on a mini-map) to choose the exact location on the map, and fill in:
  - Title (e.g., "Coffee Talk in English to Practice")
  - Location Name label (e.g., "Moda Seaside Park" or "Compound Volleyball Court B") + Map Coordinates (`lat`, `lng`)
  - Date & Time
  - Max People Limit (number, e.g., 6)
  - Emoji Selector (Quick activity emojis + full `emoji-picker-react` picker — becomes the map icon)
  - Age Limitation (`Min Age` From: e.g., 18, `Max Age` To: e.g., 27)
  - Allow Private Messages toggle (Boolean switch: "Allow people to send me Private Messages in-app")

5. EVENT POSTS, ATTENDEE PROFILE PICTURES & AGE/LIMIT GUARDRAILS:
- Every Event Post displays:
  - Large Emoji badge, Title, Date/Time, Location label, and an Age Range pill (`Ages 18–27`).
  - Live Spot Progress Bar (`4 / 6 Joined`).
  - Attendee Profile Pictures: Overlapping circular avatars (with username + age tooltip on hover) of every user who joined. Whenever a user clicks "Join Event", their profile picture immediately appears in this row!
  - Strict Join Validation:
    - If `joined >= max_people`, disable Join ("Event Full").
    - If the logged-in user's `age < min_age` or `age > max_age`, disable Join and show a clear badge: "Age restricted: This event is for ages 18–27".
    - Users who already joined can click "Leave Event" to free up their spot.

6. BUILT-IN PRIVATE MESSAGES & LIVE HOST PRIVACY TOGGLE:
- Database-backed in-app Private Messaging (`messages` table) with zero phone number required:
  - If an event has `allow_messages = true`, show a "💬 Message Host" button on the event post. Clicking it opens a clean in-app Private Chat drawer between the user and the host (linked to that event).
  - Include a "💬 Inbox" button with unread/message count in the top navbar so hosts and attendees can read and reply to private messages.
  - LIVE HOST TOGGLE (Crucial Requirement): If the logged-in user is the creator of the event, display a live toggle switch right on their posted event card: "Allow Private Messages (ON / OFF)". The host can turn private messages OFF or ON at any time after posting, which immediately updates the database, hides the "💬 Message Host" button for everyone else, and blocks new incoming chats for that event.

7. RICH PRE-SEEDED DEMO DATA:
- Pre-seed the database with 5 demo users (ages 19, 21, 24, 26, 31 with distinct avatars) and 6 realistic events pinned around the map ("Coffee Talk in English to Practice ☕", "Compound Volleyball Match 🏐", "Morning 5K Running Group 🏃", "Coffee Talks & Book Swap 🗣️", "UI/UX & Coding Study Session 📚", "Evening Board Games 🎲") with 2–4 joined attendee profile pictures and sample private messages already loaded.
